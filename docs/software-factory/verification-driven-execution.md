# Autonomous implementation and verification

After human approval of objective, scope and DoD, autonomously recover requirements, implement, test, repair and reverify. Exhaust available sources before asking routine questions. Never weaken criteria or misrepresent evidence. Persist each iteration, unresolved defects and next actions. Escalate only genuine dependencies, conflicts or authorization boundaries. Stop as NOT_DONE if budget or access prevents progress; do not imply background work.

Keep development verification separate from per-run QA and release. Product workflows are independent; shared infrastructure must not import product-specific logic. Keep weekly behavior unchanged. A machine-ready result is not human approval. Evidence must bind target revision; changes invalidate dependent verification. Verify educational and visual quality independently of structural checks. Regression never publishes to PrintReady.
